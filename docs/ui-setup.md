# 全程通过界面配置

About 位于主页面和密码页左上角 logo 名称后的小字链接中，悬停 logo 或键盘聚焦时显示。页面开头介绍项目名称、用途和当前开发范围，再显示完整构建信息：`build 007 (提交哈希[-dirty]) at 构建时间`。编译时存在未提交的更改（含暂存内容及未被忽略的未跟踪文件），哈希后加 `-dirty`；忽略文件不参与 dirty 判断。启动页显示 `build 007`，debug 主界面也在 `PRIVATE BY DESIGN` 下显示简写。完整信息通过 Rust 编译脚本写入应用，不依赖运行电脑上的 Git 或外部版本文件。

构建编号等于 `git rev-list --count HEAD`，包括初始提交以及 HEAD 可达的其他提交；dirty 时额外加 1。编号至少三位，不单独维护计数文件。重复编译或打包多个架构不改变编号；将未提交改动提交后，提交数加 1、dirty 的额外 1 消失，因此编号保持一致。完整元数据缓存在被 Git 忽略的 `.build-info-state.json` 中，相同源码、提交和 dirty 状态共用构建时间；变化时更新时间。编译脚本每次检查 Git 状态，暂存或提交操作也能更新显示。macOS 开发版可用 `sh scripts/package-macos.sh --debug` 打包；请保留完整 Git 历史，浅克隆的提交数可能偏小。

## 打开软件

macOS 发行包内有 **CipherWhisper.app**。双击后会打开默认浏览器，进入本机启动向导；无需安装 Rust、Node 或手动生成证书。界面和所有管理操作只允许本机访问。

默认身份与历史保存在 `~/Library/Application Support/CipherWhisper/`。以后继续使用同一目录和原口令，不会重新创建身份。旧的 `serve`、`connect` 命令继续兼容；应用默认目录与以前手动指定的目录可能不同，不会自动搬迁旧历史。

开发时可直接运行 `./target/debug/cipherwhisper`；无参数也进入 UI 模式。高级用法 `cipherwhisper ui --data <已有或新目录>` 可以选择工作区，`--bind 127.0.0.1:0 --no-open` 适合受控测试。一个目录只能运行一个配置窗口；再次启动同一目录会打开已有窗口。默认界面端口被占用时自动换用可用端口。

## 创建聊天中心

1. 选择「创建聊天中心」，填写名称和口令，再次确认口令。至少 12 字节；口令不会写入配置文件，目前没有找回功能。
2. 确认「这台电脑的连接地址」。程序会建议本机地址；应填写对方实际能访问的局域网 IP、Tailscale IP 或域名。仅本机试用可填写 `localhost`。
3. 使用默认聊天端口，或在界面修改。如果自己的其他设备也要连接，勾选「允许自己的其他设备连接」。
4. 点击「创建并继续」。后台创建稳定身份、自动生成 HTTPS 证书、保存连接设置并启动聊天。

双方点击左下角自己的身份，下载 `.peer.json` 连接卡并交换。点击联系人「＋」选择对方的连接卡，程序验证签名并导入地址与公开 CA。仍需通过可信渠道核对完整身份指纹，双方都要导入对方。可以在联系人详情「测试 P2P 连接」，然后创建话题并聊天。

证书有效期一年。远程连接验证证书、主机名和稳定身份签名；不会关闭验证，也不会修改系统信任库。跨互联网需要双方地址可达；程序不自动打通路由器、防火墙或 NAT。

## 连接自己的其他设备

1. 在另一台电脑打开同一软件，选择「连接自己的中心」，填写设备名称和独立口令。
2. 点击「创建并继续」，下载本设备的 `.device.json` 身份卡。
3. 中心在「连接与证书设置」开启设备连接，然后在「域内设备管理」导入设备卡，核对完整设备指纹，点击「授权设备并下载配对文件」。
4. 在设备的配对页面选择这个文件，并填写通过可信渠道核对的完整中心 `td_…` 指纹，点击「验证配对并连接」。

设备独立保存密钥和历史副本。中心可在 UI 撤销设备。设备不获得中心私钥；已缓存历史不会因撤销而擦除。外部 P2P 连接卡在中心导入。

## 后续设置与解锁

「连接与证书设置」可以修改地址、端口、开启或关闭设备连接，并重新生成证书。改变地址时会自动换发证书。保存后后台自动应用设置；端口冲突等启动失败会恢复原配置。身份、联系人和历史保持原样。

改变聊天地址、聊天端口或证书后，重新下载连接卡给联系人。设备地址、设备端口或证书改变后，从中心重新导出已有设备的配对文件；设备在「连接与证书设置」导入并核对原中心指纹。

刷新页面或锁定界面后，只需输入工作区口令解锁。点击「关闭工作区」会停止聊天后台并清除内存口令；再次输入口令即可启动。「退出软件」会关闭配置后台和聊天后台。关闭浏览器标签页只关闭页面，不停止后台；再次双击软件可以重新打开页面。

公开设置保存在 `ui-config.json`，证书和私钥保存在工作区的 `tls/` 内，私钥权限为 0600。口令只在正在运行的配置后台内存中保留，用于应用设置时重新打开密钥保险库；不写到磁盘、不放入 URL 或启动参数。旧证书目录保留在本机，不通过连接卡分享私钥。
